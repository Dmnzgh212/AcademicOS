# 第 02 步 · PPT 工作区静态骨架

本模块只实现第 2 页的页面结构：项目树、面包屑/连接状态、三个工作区页签、并排原材料与报告、独立运行栏。内部内容留槽，不读取文件、不生成报告、不启动运行、不连接浏览器、不写个人记录。

## 查看

直接在桌面浏览器打开 [index.html](index.html)。这是自包含静态文件，CSS 与选用 SVG 已嵌入；无需服务器、安装依赖或模型 API。文件名为示例，页数和运行状态未接入。窄于 1120px 时横向滚动桌面画布，本阶段不做移动布局。

GitHub 的文件页展示源码；可下载 `index.html` 后直接打开。尚未替换线上网站。

## 文件

| 文件 | 用途 |
| --- | --- |
| `skeleton.js` | 导出 `workspaceSkeleton()`，只返回骨架标记 |
| `skeleton.css` | 独立作用域与布局尺寸，不引入旧全局页面样式 |
| `build-preview.mjs` | 用已有 Lucide 图标与许可证生成静态预览 |
| `index.html` | 生成的自包含预览，无运行时脚本 |

从本模块目录执行 `node build-preview.mjs` 可重新生成预览。节点版本使用项目现有 Node 环境即可，不增加依赖。图标来自已有 `ui/icons.js`，原许可证见 `vendor/lucide-LICENSE.txt`，生成文件也内嵌了声明。
