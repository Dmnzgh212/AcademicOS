## 结构尺寸

这些是从 PPT 窗口比例估计的起点，不是已经测量完成或验收通过的精确像素：

- 基准视口：1600×900。
- 左侧：`clamp(190px, 14.4vw, 260px)`，基准下 230.4px。
- 顶栏：50px；工作区栏：48px；状态栏：24px。
- 运行栏网格轨道：`clamp(280px, 20vw, 360px)`，基准下 320px。
- 阅读区域扣除运行栏、间距与内边距后的两栏比例：44:56。
- 三块面板使用同一 Grid 行，顶部与底部对齐；正文在各自面板内滚动。
- 本阶段保持桌面结构，最小画布宽度 1120px、最小高度 580px；更小窗口允许滚动画布，不自动把两块阅读面板堆成一列。

CSS 单独作用域为 `s02-`，未引入旧全局页面样式。图标复用已有 Lucide 文件与许可证，没有增加依赖。
