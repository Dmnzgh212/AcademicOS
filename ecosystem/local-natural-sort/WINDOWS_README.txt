LifeHub 本地自然排序 Windows 试用包

前提：已安装 Windows x64 Python 3.12，并可从 PATH 启动 python。
本包没有内置 Python，不是完整桌面安装程序。无需 Zig、C 或 Wasm 编译器。

1. 将ZIP完整解压到你可写的目录。不要直接在压缩包中运行。
2. 双击 Start.cmd。它创建包内 .venv 并仅从 wheels 目录离线安装依赖。
   首次准备会写入本目录；不访问网络，不需要管理员权限。
3. 选择1导入，阅读审查结果；输入 yes 才确认安装。
4. 选择2授权本地排序；输入 yes 确认。安装本身不会授予此权限。
5. 选择3，每行输入一个英文名称，空行开始排序，例如 Lecture 10 / Lecture 2。
6. 选择4撤销后，再排序应失败。选择5并确认可卸载模块。
7. 选择0退出。排序是单次运行，没有需要继续管理的后台任务。
   退出菜单不会自动撤销权限，重开后选择4可撤销。

限制：最多16个ASCII名称，每个64字符。中文名称暂不支持；不读取文件内容。
输入只交给本地Wasm模块，无网络、存储或外部效果权限。
workspace保存本地安装/授权状态；不应将整个目录发送给别人。
发生错误，只复制LHSORT开头的代码，不发送私有名称、数据库或原始堆栈。
KIT_MANIFEST用于检查意外修改，不是签名；只使用可信来源的工程审查包。
包内NOTICE保留开源归属和许可。CI烟测不等于在你的电脑上已验收。
