# Research Archive Status

Initial open-source research archive completed for the Calendar-first architecture on 2026-09-25.

The archive now contains focused dossiers for Brightspace acquisition, deterministic scheduling, time tracking, dynamic urgency, constraint solvers, local activity feedback, local knowledge/RAG, Ollama optimization, request-path acceleration, and Zoom shared recordings.

This marker does not mean research is permanently finished. Each implementation phase should update the relevant dossier with:

- the exact upstream commit/tag reviewed;
- current license verification;
- concrete source files adapted;
- benchmark or integration findings;
- deviations from the initial design.
